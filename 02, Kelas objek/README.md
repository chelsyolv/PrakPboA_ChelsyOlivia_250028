# Modul 02: Kelas, Objek, dan Enkapsulasi

Praktikum mengenai penerapan prinsip enkapsulasi (information hiding), penggunaan *access modifier* `private`, serta validasi data masukan melalui *constructor* dan *helper method*.

## Poin Utama
- Atribut bersifat `private` atau `final` untuk menjaga integritas data.
- Validasi ketat (penolakan nilai kosong/null dan rentang angka 0–100).
- Penerapan *getter* tanpa *setter* untuk menjaga *immutability* atribut tertentu.
