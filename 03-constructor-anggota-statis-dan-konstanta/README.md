# Modul 03: Constructor, Anggota Statis, dan Konstanta

Praktikum mengenai penggunaan konstanta (`public static final` / `public const`), delegasi *constructor* `this(...)`, pengelolaan variabel statis penghitung objek, serta pembuatan method statis utilitas.

## Poin Utama
- Penggunaan konstanta untuk menghindari *magic numbers*.
- Field statis untuk menghitung total instansiasi objek `RekeningBank`.
- Validasi transaksi keuangan (setor, tarik, dan potongan biaya administrasi).
