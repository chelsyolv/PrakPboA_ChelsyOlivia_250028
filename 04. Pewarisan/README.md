# Modul 04: Pewarisan (Inheritance)

Praktikum mengenai konsep pewarisan sifat dari *superclass* ke *subclass*, pemanggilan `super(...)` pada constructor, serta *method overriding* untuk perhitungan gaji pegawai.

## Daftar Kelas
- `Pegawai.java`: Superclass utama atribut pegawai dan gaji pokok.
- `PegawaiTetap.java`: Subclass dengan tambahan tunjangan tetap.
- `PegawaiKontrak.java`: Subclass dengan tambahan perhitungan lembur.
